# Void Pointer with calloc()

## Author
M.Likitha

## Description
This program demonstrates using a void pointer with
calloc() for dynamic memory allocation.

calloc() allocates memory for multiple elements and
initializes all allocated bytes to zero.

## Concepts Used
- Void pointer
- calloc()
- Dynamic memory allocation
- Type casting
- Array access
- free()

## How to Run

gcc void_pointer_calloc.c -o void_pointer_calloc

./void_pointer_calloc

## Sample Output

Initial values:
0 0 0 0 0
